# File Browser — клиент-серверное приложение для просмотра файлов

Сервер на C++ отдаёт REST JSON API поверх заданной директории,
CLI-клиент на Python ходит по этому дереву.

## Требования

- Docker и Docker Compose v2
- больше ничего: компилятор, CMake и Python нужны только внутри контейнеров

## Быстрый старт

```bash
docker compose up --build -d server
```

## Структура репозитория

```
.
├── docker-compose.yml
├── sample-data/          демо-дерево, монтируется в контейнер как /data
├── server/               C++ + CMake
│   ├── CMakeLists.txt
│   ├── Dockerfile
│   └── src/
│       ├── main.cpp          разбор аргументов, старт сервера
│       ├── path_resolver.*   безопасное разрешение путей внутри корня
│       ├── fs_service.*      файловая система: list / stat / sha256
│       └── api.*             HTTP-маршруты и сериализация JSON
└── client/               Python CLI
```

### Коды ошибок

| Код | Когда |
|-----|-------|
| 400 | параметр `path` отсутствует или тип объекта не тот |
| 403 | путь выходит за пределы корня |
| 404 | путь не существует |
| 500 | внутренняя ошибка |

Тело ошибки — тоже JSON: `{"error": "...", "status": 404}`.
